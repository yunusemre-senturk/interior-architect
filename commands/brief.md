description: Start a discovery interview and write a confirmed design brief for a room or the whole home
argument-hint: "[room or project, e.g. kitchen, 2+1 flat]"
---
Use the interior-architect skill. Run the discovery interview for: $ARGUMENTS

1. Read the house rules and design log if they exist; do not ask what they already answer.
2. Follow `references/discovery-brief.md`: ask in short rounds of 3-4 questions (multiple choice where possible), starting with people and a day in the life.
3. Offer `assets/brief-questionnaire.md` if the user prefers to fill a form.
4. When enough is known, write the brief back: household profile, 5-8 ranked requirements, hard constraints, marked assumptions, what still needs measuring. Ask the user to confirm.
5. Save confirmed standing rules to the house-rules file and log the brief in the design log.
