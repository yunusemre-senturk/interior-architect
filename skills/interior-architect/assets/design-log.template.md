# Design log

This log is private to this household. Put the newest entry first. Write one entry for each real decision.

## YYYY-MM-DD · <space> · <element> · rev. N
- **Request:** what the user asked for, in their own words.
- **Survey:** each measured number marked M, each number read from a plan marked P, and anything taken from photos.
- **Concepts:** A / B / C, each with its idea in one line.
- **Decision:** what was chosen, and who chose it.
- **Reason:** why.
- **Rejected:** the alternatives that were turned down, and why.
- **Cost of the decision:** what the user gives up. Tell the user this.
- **Open checks:** what still has to be measured or confirmed.
- **Drawings:** where they are (canvas page, file name).
